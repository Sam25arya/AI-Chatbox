# 🌸 Bloom — Basic AI Chatbot Interface

A lightweight, beginner-friendly AI chatbot web interface built using vanilla **HTML**, **CSS**, and **JavaScript**. Powered directly by the **Google Gemini API** (`gemini-3.6-flash`), Bloom provides a smooth, pastel-themed chat experience without needing complex frameworks or backend build tools.

> ⚠️ **Project Scope Notice:** This project is a **basic frontend demonstration** built primarily for learning and prototyping. It operates purely on client-side JavaScript via simple REST requests. It does not use a backend database, backend proxy server, or advanced AI streaming pipelines.
